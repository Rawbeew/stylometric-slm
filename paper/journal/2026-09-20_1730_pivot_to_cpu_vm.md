# Journal Entry 3: Pivot to CPU VM (2026-09-20 ~17:30)

## Trigger
User increased budget from "small balance" to **$5 USD** with direction: *"Let's use a larger ram, increasing our budget to 5 usd"*

## Decision
Switched from TPU v5litepod-1 (16GB HBM, $0.74/hr) to **GCP n2-highmem-8** (8 vCPU + 64GB RAM, ~$0.43/hr).

### Math
- 5 hours × $0.43 = $2.15 (leaves $2.85 buffer)
- 10 hours × $0.43 = $4.30 (leaves $0.70 buffer)
- 24 hours × $0.43 = $10.32 (over budget)

### Cost-of-estimating time
Smoke test measured **10.4s/step at batch=2 seq=256**.
Scaling estimates:
| Seq len | Batch | Step time | 75 steps × 5 epochs |
|---|---|---|---|
| 256 | 2 | 10.4s | 65 min |
| 512 | 4 | ~25s | 156 min |
| 768 | 4 | ~50s | ~5.2 hours |
| 1024 | 2 | ~80s | ~8 hours |

**Going with seq=768 batch=4** as the best quality/time tradeoff within budget.

## VM Setup Script (one-shot)

### `vm_setup.sh`
```bash
#!/bin/bash
set -e

# 1. Apt dependencies
sudo apt-get update -qq
sudo apt-get install -qq -y python3-pip python3-venv git curl wget

# 2. Clone repo
cd $HOME
git clone https://github.com/Rawbeew/stylometric-slm.git
cd stylometric-slm

# 3. Pull train + eval splits from tunnel
mkdir -p splits
curl -sLf https://barbara-themes-forbes-shaved.trycloudflare.com/data/train.jsonl -o splits/train.jsonl
curl -sLf https://barbara-themes-forbes-shaved.trycloudflare.com/data/eval.jsonl -o splits/eval.jsonl

# 4. Pull HF_TOKEN
HF_TOKEN=$(curl -sLf https://barbara-themes-forbes-shaved.trycloudflare.com/secret/HF_TOKEN)

# 5. Install ML deps
pip install --break-system-packages \
    'torch' \
    'transformers==4.46.0' \
    'datasets<3' \
    'sentencepiece' \
    'accelerate' \
    'protobuf'   # <- needed for T5 tokenizer
```
