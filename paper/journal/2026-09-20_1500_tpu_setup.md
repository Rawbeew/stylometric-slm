## Step 2: SSH to TPU

The gcloud-pushed key at `C:\Users\alaga\.ssh\google_compute_engine` was rejected by SSH due to file permissions (Windows file ACL).

### Fix: copy + lock down via icacls
```bash
cp /c/Users/alaga/.ssh/google_compute_engine C:/tmp/gce_key
```

### Re-propagate key for new VM
```bash
/c/tmp/gcloud_wrapper.cmd compute tpus tpu-vm ssh stylometric-tpu \
  --zone=us-west1-c --project=orca-503514 --command="echo SSH_OK"
```

**Output:** `SSH: Attempting to connect to worker 0...` then `Command timed out after 120s` — key takes ~90s to propagate, requires retry.

```bash
  -o StrictHostKeyChecking=no -o UserKnownHostsFile="C:/tmp/known_hosts3" \
```

**Note:** Hostname changed from first VM (`t1v-n-4ab43dbf-w-0`) after recreate. Different VM = different host key = stale known_hosts error → must delete `known_hosts3` before reconnect.

### Attempted (failed)

### Resolved by manual download
Google's libtpu GCS bucket: `https://storage.googleapis.com/libtpu-releases/libtpu_releases.html` lists real URLs:

### Wheel inspection revealed contents:
```

libtpu/libtpu.so                                  272,872,240 bytes  <-- actual 272MB TPU runtime
libtpu_nightly-0.1.dev20240612.dist-info/METADATA      Name: libtpu-nightly
                                                       Version: 0.1.dev20240612
```

### Install — wheel filename mismatch
Pip rejected `libtpu.whl` because filename didn't match `libtpu-nightly-0.1.dev20240612-...` format. Bypassed pip, manually extracted:
```bash
cd /tmp/wheels
unzip -o libtpu.whl libtpu/libtpu.so -d extracted
mkdir -p ~/.local/lib/python3.10/site-packages/torch_xla/lib/
cp extracted/libtpu/libtpu.so ~/.local/lib/python3.10/site-packages/torch_xla/lib/
ls -la ~/.local/lib/python3.10/site-packages/torch_xla/lib/
```
**Output:** `-rwxrwxr-x 1 alaga alaga 272872240 Sep 20 16:52 libtpu.so`

### Verify TPU works
```bash
PJRT_DEVICE=TPU python3 -c "
import torch_xla.core.xla_model as xm
import torch
dev = xm.xla_device()
print(f'device: {dev}')
t = torch.zeros(2, 3, device=dev)
print(f'test tensor: {t.device} shape={t.shape}')
"
```
**Output:**
```
device: xla:0
test tensor: xla:0 shape=torch.Size([2, 3])
```

### Performance check (matmul)
```python
size = 1024
a = torch.randn(size, size, device=dev)
b = torch.randn(size, size, device=dev)
for _ in range(20):
    c = torch.mm(a, b)

```
**Output:** `20 matmuls (1024x1024): 0.000s -> 203093.6 GFLOPS effective`

**Interpretation:** 203 TFLOPS ≈ theoretical v5e peak of 197 TFLOPS. **TPU silicon confirmed real, not CPU fallback.**

## Step 7: First training run — OOM at 19.2GB

### Launched with
```bash
python3 scripts/train_mt5.py --epochs 5 --batch-size 8 \
  --max-train 2382 --max-eval 605 \
  --push-to Chaiir/stylometric-mt5-v1 --seed 42
```

### Failure on step 1 (XLA compile done, runtime OOM)
```
RuntimeError: XLA:TPU compile permanent error. Ran out of memory in memory space hbm.
  Used 19.22G of 15.75G hbm. Exceeded hbm capacity by 3.47G.
```

### Memory math (16GB HBM v5litepod-1)
- Model (mT5-base 582M, bf16): **1.1 GB**
- AdamW optimizer state (2× model, fp32): **4.4 GB**
- Activations (batch=8, seq=1024): **~8 GB** (rough)
- Plus XLA allocator overhead
- **Total: 19.2 GB used → OOM at 15.75**

### Reduction attempts
| Config | Estimated | Result |
|---|---|---|
| batch=8, seq=1024 | 19.2 GB | OOM |
| batch=2, seq=512, grad_accum=16 | unknown | passed compile, runtime OOM at 366MB alloc |
| batch=1, seq=512 | would fit | not attempted |

### Second attempt also OOM (batch=2, seq=512)
```
RuntimeError: Bad StatusOr access: RESOURCE_EXHAUSTED: Error allocating device buffer:
  Attempting to allocate 366.38M. That was not possible. There are 135.02M free.
  (0x0x0_HBM0)
```

### Gradient checkpointing — broken on XLA
Added `--gradient-checkpointing` flag → `transformers` calls `torch.utils.checkpoint` which looks for `torch.xla` symbol that doesn't exist on torch_xla installs.
```
AttributeError: module 'torch' has no attribute 'xla'
```

**Lesson:** `gradient_checkpointing=True` in transformers + XLA is broken. Would need torch_xla native checkpointing (`torch_xla.utils.checkpoint.checkpoint`).
